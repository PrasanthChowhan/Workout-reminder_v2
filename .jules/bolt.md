## 2024-06-25 - Batched Initial App Data **Learning:** Identified a Tauri IPC payload serialization bottleneck on app startup and break triggering where two separate IPC calls (`get_app_config` and `get_session_data`) were made. **Action:** Combined them into `InitialBreakDataPayload` to reduce context switching and block the main thread less. Also discovered that `tokio::join!` can be used to run the async db queries concurrently inside the batched command to get extra micro-optimization.
## 2024-06-25 - Animated Width in CSS **Learning:** Discovered a CSS Module reflow/repaint trigger specific to the desktop window rendering where `.hold-progress-bar` was animating `width`. **Action:** Updated it to animate `transform: scaleX(...)` with `transform-origin: left` instead to ensure hardware acceleration and prevent layout thrashing.
## 2024-10-27 - Batch Bulk Insertions **Learning:** Replaced nested loops and multi-query invocations (N+1 query problem) in `save_app_config` with batched inserts using `sqlx::QueryBuilder`. To abide by SQLite's 999 parameter limitations, the arrays of structs were correctly chunked in sizes of (999/N params) and processed securely, dropping insert time drastically.
